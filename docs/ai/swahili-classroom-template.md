# Kiswahili classroom slide standard

Use the existing `SwahiliTeachingSlides` presenter and the shared `buildSwahiliClassroomStages` adapter for every published pack. Order: introduction, music, listening, reading, vocabulary/video support, grammar and corrections, practice, speaking/role-play, individual presentation, writing, workbook/summary. Add a `classroomSupport` object (or a keyed entry in `swahiliClassroomSupport.js`) with `glossary` pairs `[exact reading phrase, English explanation]`, five `checks` pairs `[question, answer]` or five existing `reading-*` question stages, `role` `[title, learner A instruction, learner B instruction, useful phrase]`, and an optional `presentation` prompt when the pack lacks an authored presentation. The reading stage must contain the actual text in `content` or `items`. Use existing workbook material or label new classroom practice; do not change graded workbook keys. No new AI calls are needed.

A1 radio stages are excluded from the classroom presenter, including linked videos, episode-dependent questions and radio placeholders. Existing teacher-led listening remains; use a plain listening placeholder when no standalone classroom audio exists. Keep private signed classroom recordings for B1 and future teacher-approved audio. Do not invent R2 keys or mark unpublished lessons as available. The original archived radio exercise data is retained outside the visible sequence for reference and historical tests.
