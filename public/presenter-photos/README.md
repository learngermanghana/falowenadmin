# Falowen classroom photo starter pack

These four photographs are included in the Admin site's static /presenter-photos
folder. They are selectively displayed on eligible introduction and short
vocabulary slides. The presenter does not call any image search API or Firebase
service at runtime. All images are decorative; marking, timers and navigation
have priority and the pictures disappear on narrow or short viewports.
